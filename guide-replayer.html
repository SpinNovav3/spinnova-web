🎬 Replayer — Revivez Vos Mains

Table simulée pour rejouer chaque main action par action. Board progressif, HUD intégré, et vérification GTO preflop en temps réel. Pas besoin d'images — tout est reconstruit visuellement.

Replayer — Table simulée avec cartes, board progressif, stacks et panel GTO preflop

🎯 Fonctionnalités

🎬 Stepping Action par Action

Naviguez avec ◀ ▶ pour avancer ou reculer action par action. Raccourcis clavier : PF / F / T / R / SD pour sauter directement à une street.

🃏 Table Visuelle Sans Images

Cartes, board, stacks, pot, dealer button — tout est dessiné dynamiquement. Supporte 2 à 10 joueurs avec placement automatique.

📊 Vérification GTO Preflop

Le panneau latéral affiche les fréquences GTO pour la situation preflop en cours. Comparez l'action jouée aux fréquences optimales.

🖥️ HUD Réel Intégré

Vos vrais HUD SpinNova s'affichent sur la table du replayer — notes, badges, stats. Comme si vous étiez en jeu.

📖 Comment ça marche

  1. Ouvrez la fiche d'un joueur dans l'onglet Joueurs
  2. Allez dans l'onglet 🎬 Replayer
  3. Filtrez par mode, position, pot ou résultat si besoin
  4. Sélectionnez une main et cliquez Ouvrir Table Simulée
  5. Naviguez action par action avec ◀ ▶ ou les raccourcis street
  6. Le panel GTO vous montre les fréquences optimales pour chaque situation preflop

❓ Questions Fréquentes

Ça fonctionne avec toutes les rooms ?

Oui, le replayer utilise les hand histories importées dans SpinNova. Toutes les rooms supportées par le logiciel sont compatibles avec le replayer.

C'est quoi la vérification GTO ?

Quand vous êtes sur une action preflop dans le replayer, le panneau latéral affiche les fréquences GTO calculées par solver pour cette exact situation (depth, position, action vilain). Vous voyez instantanément si l'action jouée était optimale.

Pourquoi pas besoin d'images ?

Le replayer reconstruit tout visuellement : la table, les cartes, le board, les stacks, le pot. Tout est dessiné dynamiquement à partir des données du hand history — pas de screenshots nécessaires.
