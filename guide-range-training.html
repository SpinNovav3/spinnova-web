📖 Mode d'Emploi

🏋️ Range Training — Entraînez-vous

Quiz interactif sur vos propres ranges. Testez combo par combo si vous connaissez votre plan preflop.

Range Training — Quiz QJo Offsuit, OpenRaise 20bb+

🎯 Fonctionnalités

🎲 Quiz Combo par Combo

Un combo s'affiche, vous choisissez l'action parmi Raise, Call, 3-Bet, All-in, Fold. Feedback instantané — bon ou mauvais.

📋 Sélection Multiple

Sélectionnez une ou plusieurs ranges à entraîner. Cochez/décochez dans l'arborescence à gauche.

🔀 Modes Aléatoire / Séquentiel

Mode Aléatoire pour tester votre mémoire, ou Séquentiel pour parcourir systématiquement.

🐟 Variantes Fish / Reg

Entraînez-vous sur vos ranges spécifiques vs Fish ou vs Reg. Sélection via le bouton Tous/Fish/Reg.

📖 Comment ça marche

  1. Ouvrez l'onglet Range Training dans la barre latérale
  2. Cochez les ranges que vous voulez entraîner dans l'arborescence
  3. Choisissez le mode (Aléatoire ou Séquentiel)
  4. Cliquez START — un combo s'affiche avec son contexte (spot + stack)
  5. Cliquez sur l'action correcte — le score se met à jour en temps réel
  6. Les dernières erreurs s'affichent à droite pour révision

Construisez vos ranges d'abord 🎲

Créez et comparez vos ranges dans le Range Editor avant de vous entraîner.
