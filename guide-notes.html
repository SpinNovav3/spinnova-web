⚡ Quick Notes — 1 clic = 1 note

Quick Notes en jeu — 1 clic sur la pastille

Notes instantanées pendant le jeu

Les Quick Notes sont des templates prédéfinis que vous appliquez en 1 clic. Cliquez sur la pastille Quick Note dans le HUD, choisissez votre template, et c'est noté.

  • → 3 catégories : Preflop, Postflop, Général
  • → Templates personnalisables dans le logiciel
  • → Glisser-déposer pour réorganiser

🛠️ Personnaliser les Templates

Créez vos propres templates de Quick Notes dans le logiciel. Organisez-les par catégorie et réordonnez-les par glisser-déposer.

L'éditeur de templates Quick Notes dans SpinNova

✏️ Notes Manuscrites

Écrivez ce que vous voulez

Cliquez sur l'icône de notes dans le HUD pour ouvrir l'éditeur de notes. Écrivez librement vos observations sur le joueur.

  • → Texte libre pour écrire vos observations
  • → Sauvegarde automatique
  • → Visible sur tous les formats (HU, 3-way)
