Comment obtenir mon HWID ? 🔑 +
Télécharge le logiciel sur la page Installation, lance-le, et une fenêtre apparaîtra avec ton code HWID. Clique sur "COPIER" et colle-le dans le formulaire d'essai ou dans ton message de support.
Mon antivirus bloque le logiciel, que faire ? ⚠️ +
C'est un faux positif classique avec les logiciels de profilage qui lisent l'écran (OCR). Ajoute une exception pour le dossier SpinNova dans Windows Defender ou ton antivirus. Nos fichiers sont 100% sains.
Le HUD ne s'affiche pas sur ma table, pourquoi ? ❌ +
Vérifie que :
1. Ton lobby iPoker/Winamax est bien en Français, Anglais, Italien ou Espagnol.
2. Tu as bien configuré le chemin du fichier hand history dans les paramètres.
3. Ton pseudo est écrit exactement comme sur le lobby (majuscules/minuscules incluses).
4. Ton HWID a bien été activé par notre équipe.
