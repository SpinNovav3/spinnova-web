  • Vert = Action rare (peu fréquente)
  • Bleu = Action modérée (fréquence moyenne)
  • Rouge = Action fréquente (attention danger !)
LC - Limp-Call Limp puis call une relance. Profil passif.
LR - Limp-Raise Limp puis relance (trap). Attention aux monsters !
LF - Limp-Fold Limp puis fold vs raise. Exploitable !
OP - Open Fréquence d'open raise. Rouge = wide range.
OS - Open-Shove Open all-in. Rouge = shove light !
IS - Iso Size Sizing d'isolation vs limpers.
IAI - Iso All-In Iso shove vs limpers. Profil aggro.
3B - 3-Bet Fréquence de 3-bet. Rouge = 3-bet light.
F/OP - Fold vs Open Fold face à un open. Tight player.
COS - Call Open-Shove Call les open-shoves. Rouge = calling station.
