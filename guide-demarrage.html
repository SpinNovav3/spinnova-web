🚀 Guide de Démarrage

De l'installation à votre première session, tout est fait pour être simple et rapide.
En 3 étapes, votre HUD est prêt.

Étape 1 — Télécharger & Installer

Installation en 2 minutes

  • 1. Téléchargez SpinNova depuis la page de téléchargement
  • 2. Lancez l'exécutable — aucune installation système requise
  • 3. Activez votre licence via Discord ou Email

💡 Essai gratuit 3 jours — pas besoin de carte bancaire !

Étape 2 — Configurer vos Rooms

Multi-room automatique

SpinNova détecte automatiquement vos rooms installées. Vérifiez simplement dans Paramètres que les bons chemins sont configurés.

🏇 PMU Poker 🎰 FDJ 🃏 Winamax

Toutes les rooms du réseau iPoker + Winamax sont supportées nativement.

Étape 3 — Lancer une Table, le HUD Apparaît

Automatique et immédiat

Ouvrez SpinNova, puis ouvrez une table de poker. Le HUD s'affiche automatiquement au-dessus de la table avec toutes les informations de vos adversaires.

  • → Le bouton ❤️ SpinNova apparaît sur la table
  • → Les étiquettes HUD s'affichent sur chaque joueur
  • → Cliquez sur une étiquette pour voir les notes et badges

Bonus — Personnaliser l'Opacité

HUD semi-transparent

Réglez l'opacité du HUD pour qu'il ne gêne pas votre vision du jeu. Le slider se trouve dans Paramètres → Opacité HUD.

Découvrez maintenant les 3 modes HUD ou lancez-vous directement.
