Personnalisation

Créez Vos Badges Personnalisés

SpinNova vous offre une liberté totale : créez des badges texte, importez vos propres images, et organisez-les comme vous le souhaitez.

✏️ Créer un Badge Texte

3 étapes pour créer un badge unique en quelques secondes.

1

➕ Cliquez sur "+ NOUVEAU"

Le panneau de création s'ouvre. Saisissez 2 à 4 caractères pour votre badge.

2

🎨 Personnalisez

Choisissez la couleur du texte et du fond. L'aperçu se met à jour en temps réel.

3

✅ Votre badge est prêt !

Il apparaît immédiatement dans votre liste. Vous pouvez l'assigner à vos adversaires.

🖼️ Importer une Image

Utilisez vos propres images comme badges personnalisés.

1

📁 Cliquez sur "Importer Image"

Sélectionnez une image sur votre ordinateur (PNG, JPG, etc.).

2

📂 Choisissez la catégorie

Preflop ou Postflop ? Décidez où placer votre nouveau badge image.

3

✅ Badge image ajouté !

Votre image devient un badge utilisable comme tous les autres.

↔️ Organisez Vos Badges

Déplacez librement vos badges entre les onglets.

🔄 Mode Sélection

Activez le mode sélection pour déplacer un ou plusieurs badges entre :

  • PRE - Onglet Preflop
  • POST - Onglet Postflop
  • IMP - Onglet Imported

Réorganisez votre arsenal selon votre style de jeu !
