Personnalisation

Créez Vos Badges Personnalisés

SpinNova vous offre une liberté totale : créez des badges texte, importez vos propres images, et organisez-les comme vous le souhaitez.

✏️ Créer un Badge Texte

3 étapes pour créer un badge unique en quelques secondes.

1

➕ Cliquez sur "+ NOUVEAU"

Le panneau de création s'ouvre. Saisissez 2 à 4 caractères pour votre badge.

2

🎨 Personnalisez

Choisissez la couleur du texte et du fond. L'aperçu se met à jour en temps réel.

3

✅ Votre badge est prêt !

Il apparaît immédiatement dans votre liste. Vous pouvez l'assigner à vos adversaires.

🖼️ Importer une Image

Utilisez vos propres images comme badges personnalisés.

1

📁 Cliquez sur "Importer Image"

Sélectionnez une image sur votre ordinateur (PNG, JPG, etc.).

2

📂 Choisissez la catégorie

Preflop ou Postflop ? Décidez où placer votre nouveau badge image.

3

✅ Badge image ajouté !

Votre image devient un badge utilisable comme tous les autres.

↔️ Organisez Vos Badges

Déplacez librement vos badges entre les onglets.

🔄 Mode Sélection

Activez le mode sélection pour déplacer un ou plusieurs badges entre :

  • PRE - Onglet Preflop
  • POST - Onglet Postflop
  • IMP - Onglet Imported

Réorganisez votre arsenal selon votre style de jeu !

🎁 Les Packs de Badges Pré-installés

Des badges prêts à l'emploi dès le premier lancement.

📦 Pack Bienvenue

Inclus dès l'installation, ce pack contient les badges essentiels pour commencer à profiler vos adversaires :

  • Preflop : limp, open, 3bet, fold, etc.
  • Postflop : cbet, check-raise, barrel, etc.

Un second pack Pro Avancé est également disponible pour un profilage plus fin.

Vue d'ensemble de l'éditeur de badges avec les onglets Preflop / Postflop / Importés

🎯 Assigner un Badge en Jeu

Un clic sur le joueur, un clic sur le badge. C'est fait.

💬 La popup de badges

Directement depuis le HUD en jeu, cliquez sur l'icône badge d'un joueur. La popup s'ouvre avec tous vos badges disponibles.

  • → Cliquez pour assigner ou retirer un badge
  • → Les badges assignés apparaissent immédiatement sur le HUD
  • → Fonctionne en 3-way comme en Heads-Up

📥 Colonne Importés

Pour les joueurs qui migrent depuis SiQnotes ou un autre outil.

🔄 Migration facile

Si vous aviez des notes ou badges sur un autre outil, SpinNova peut les importer. La colonne Importés dans la popup badges vous permet de retrouver vos anciens badges.

  • → Compatible avec les exports SiQnotes
  • → Badges automatiquement classés dans l'onglet IMP
  • → Réorganisez-les ensuite comme vous voulez
