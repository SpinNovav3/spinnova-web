Installer SpinNova

📥 Télécharger la Dernière Version (V3.0.0)
1

Extraction & Installation

Une fois le fichier ZIP téléchargé, extrais le contenu dans un dossier sur ton bureau (ou ailleurs).

Lance ensuite SpinNova.exe pour démarrer l'application.

2

Fenêtre d'Activation

Au premier lancement (ou si ta licence expire), la fenêtre d'activation s'ouvre automatiquement.

1. Clique sur "COPIER" pour copier ton HWID unique.
2. Choisis ton mode d'activation :

🎮 DISCORD (Instantané)

Notre bot IA génère ta licence en quelques secondes. Colle ton HWID dans le salon.

✉️ EMAIL (24-48h)

Pas de Discord ? Le formulaire pré-remplit ton HWID. Tu reçois le code par mail.

3

Colle ton Code & C'est Parti !

Une fois le code d'activation reçu (Discord ou Email), colle-le directement dans la zone prévue.

💡 Astuce : Le logiciel détecte automatiquement le code et s'active tout seul !

🎉 C'est tout !

Après activation, SpinNova démarre et tu peux commencer à profiler tes adversaires. Le HUD s'affiche automatiquement sur tes tables iPoker.

Configuration Requise :

• Windows 10 ou 11 (64 bits)
• Réseau iPoker (PMU, FDJ, Bwin...)
• Logiciel de poker en Français, Anglais, Italien ou Espagnol.
